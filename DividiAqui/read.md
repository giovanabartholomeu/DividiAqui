# 💸 DividiAqui

Sistema simples e funcional para controle de **gastos compartilhados em grupo**.  
Ideal para dividir contas de viagens, jantares, aluguel e outras despesas entre amigos ou colegas.

---

## ✅ Funcionalidades

- Criar grupos de usuários
- Adicionar gastos ao grupo
- Definir quem pagou e quem participou do gasto
- Calcular automaticamente **quem deve para quem**
- Exportar o resumo financeiro do grupo em PDF

---

## 🛠 Tecnologias

- Java
- Spring Boot
- Banco de Dados relacional (PostgreSQL)
- PDF: iText 
- Swagger para documentação e geração de código da API

---
